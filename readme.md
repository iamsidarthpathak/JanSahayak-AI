# JanSahayak AI

An AI-powered platform that helps citizens discover government schemes they are eligible for.

## 📌 About the Project

JanSahayak AI is a web application designed to help users find government schemes they are eligible for by answering a few simple questions. The goal is to make government benefits easier to discover and access.

## 🚀 Current Status

🚧 The project is currently under development.

## ✨ Planned Features

- AI-powered eligibility checking
- Government scheme recommendations
- Search and filter schemes
- User authentication
- Personalized dashboard
- Official application links
- Responsive design
